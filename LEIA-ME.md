# Níquel, assistente financeiro: como colocar no ar e instalar no celular

## Parte 1: publicar no GitHub Pages (uma vez só, uns 5 minutos)

1. Entre em https://github.com e faça login (ou crie uma conta gratuita).
2. Clique em **+** (canto superior direito) > **New repository**.
3. Nome: `orcamento`. Marque **Public** e clique em **Create repository**.
4. Na página do repositório, clique em **uploading an existing file**.
5. Descompacte o zip no seu computador e arraste para o GitHub **o conteúdo da pasta**: `index.html`, `manifest.webmanifest`, `sw.js` e a pasta `icons`. (Os arquivos têm que ficar na raiz, não dentro de outra pasta.)
6. Clique em **Commit changes**.
7. Vá em **Settings** > **Pages**. Em **Branch**, escolha `main` e a pasta `/ (root)`. Clique em **Save**.
8. Espere cerca de 1 minuto e recarregue a página. O endereço aparece no topo, assim:
   `https://SEU-USUARIO.github.io/orcamento/`

## Parte 2: instalar no celular

Abra o endereço acima no celular.

- **iPhone (use o Safari):** toque em Compartilhar > **Adicionar à Tela de Início** > Adicionar.
- **Android (Chrome):** toque no menu ⋮ > **Instalar app** (ou **Adicionar à tela inicial**).

O ícone do Níquel aparece na tela inicial e o app abre em tela cheia, também sem internet.

## Importante

- A aba **Eventos** lista as despesas marcadas com “Repetir todo mês” por dia de vencimento, com aviso de atraso e botão “Marcar como pago” (a marcação vale só para o mês em que você fez).
- A sobra de cada mês passa para o mês seguinte. Se você registra “Saldo que tenho” todo mês, desative isso em **Planejar > Sobra entre meses** para não contar o mesmo dinheiro duas vezes.
- Os dados ficam **só no aparelho** em que você os digitou. Celular e computador não se sincronizam.
- Limpar os dados do navegador, ou desinstalar o app, apaga os lançamentos. Use **Planejar > Exportar para planilha (CSV)** de vez em quando para ter uma cópia.
- O endereço do GitHub Pages é público, mas seus dados não vão para lá: ficam no seu aparelho.
- Para atualizar o app no futuro, basta subir os arquivos novos no GitHub. Os aparelhos pegam a versão nova ao abrir o app com internet.
- Os lançamentos que você digitou na versão do Claude **não passam** para este app: o app instalado começa vazio.
